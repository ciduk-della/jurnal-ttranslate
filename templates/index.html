ℹ️ Panduan Konversi PowerPoint

LibreOffice Belum Terdeteksi

Untuk mengonversi file biner PowerPoint (.pptx / .ppt) secara langsung di server, sistem memerlukan LibreOffice command line tool (gratis & open-source).

Cara Pasang LibreOffice (Gratis):

  • Windows (via PowerShell/Terminal): 
    winget install TheDocumentFoundation.LibreOffice
  • Windows (Unduh Installer):

    Kunjungi libreoffice.org lalu unduh dan pasang.

  • Linux (Ubuntu/Debian): 
    sudo apt-get install libreoffice
  • macOS: 
    brew install --cask libreoffice

Alternatif Cepat (Langsung Berfungsi Sekarang):

Anda dapat membuka presentasi di PowerPoint / Google Slides, lalu pilih File > Save As / Export to PDF. Kemudian unggah file PDF tersebut ke Free Corat-Coret PPT. Semua fitur anotasi, coretan, dan ekspor bekerja 100% langsung!
